# A biology-informed uncertainty model for toxicological QSAR

This repository contains the minimum input data
and computation code, and one final PNG or CSV for each article result and
reviewer-requested scientific check. It deliberately excludes build logs,
hashes, generated caches, notebook checkpoints, stored fitted models, raw
prediction dumps, and internal working files.

## Scope

This is a reproducibility repository, not an article-submission folder. It deliberately contains no manuscript, Supplementary Information, tracked PDF, or reviewer-response PDF. Those documents are rendered and maintained separately.

## Reproduction layout

- `data/` — active molecular data, exclusions, target annotation,
  and the fixed structural split assignments.
- `notebooks/` — numbered calculation workflow.
- `scripts/` — reusable implementations called by notebooks.
- `results/figures/` — final figures.
- `results/tables/` — final article tables and scientific
  summaries for reviewer-requested checks.
- `results/models/` — trained models, calibration predictions,
  and test predictions generated by notebook 02; not distributed.

The workflow does not create temporary result folders. During model training, reusable
model files, predictions, and aggregate training metrics are written only to
`results/models/`; all reader-facing outputs are written directly
to `results/figures/` or `results/tables/`.

Notebooks have no stored execution output. Their source contains final artifact
preview cells, so executing a notebook displays the PNGs and tables it produces.

Run the numbered notebooks in order from ``. The calculation
workflow creates its derived model files locally under `results/models/`; they
are intentionally not distributed in this package.

## Clean-environment run

The workflow was tested with Python 3.14. Create a new virtual environment,
install the compact dependency list, and run the notebooks in numeric order
from ``:

```bash
VENV=/path/outside/the/package/tox-repro-venv
python3 -m venv "$VENV"
"$VENV/bin/python" -m pip install --upgrade pip
"$VENV/bin/python" -m pip install -r requirements.txt

for notebook in notebooks/[0-9][0-9]_*.ipynb; do
  "$VENV/bin/jupyter" nbconvert --to notebook --execute --inplace \
    --ExecutePreprocessor.timeout=0 "$notebook"
done
```

The workflow uses only the supplied package data and does not require network
access or external command-line tools.

## Scientific limits

The 30 Butina cluster-disjoint splits are internal resampling of one historical
cohort. They are not external, prospective, temporal, regulatory, or causal
validation. Docking and ADMETLab quantities are structure-dependent,
model-derived descriptors, not experimental binding measurements.
